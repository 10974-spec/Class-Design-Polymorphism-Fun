# Class-Design-Polymorphism-Fun
Class Design &amp; Polymorphism Fun
🚀 OOP Programming Assignment: Class Design & Polymorphism
📋 Assignment Overview
This assignment challenges you to explore two fundamental Object-Oriented Programming concepts:

✨ Class Design with inheritance

✨ Polymorphism through method overriding

🏗️ Assignment 1: Design Your Own Class!
🎯 Task Requirements:
Create a custom Python class representing any real-world object

Implement attributes and methods to bring your class to life

Use __init__() constructor to initialize objects

Add inheritance to demonstrate code reusability

Explore encapsulation with proper access modifiers


🎭 Assignment 2: Polymorphism Challenge!
🎯 Task Requirements:
Create multiple classes with the same method name

Implement different behaviors for that method in each class

Demonstrate polymorphism by calling the method on different objects
